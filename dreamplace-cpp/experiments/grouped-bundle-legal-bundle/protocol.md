# Grouped Pre-Legal Bundle And Fixed-Topology Legal Bundle

Status: exploratory, protocol locked before implementation

## Hypothesis

A smooth placement generated by this program provides the global topology.
Exact gradient sampling plus independently aggregated net-group cuts can then
explore the 7% overflow boundary, while a post-legal fixed-row, fixed-segment,
fixed-order bundle can convert pre-legal improvement into final legal HPWL.

## Isolation Requirements

- All new behavior is opt-in and disabled by default.
- The center-initialized exact-HPWL path and its existing options retain their
  current behavior.
- The warm start must be an output produced by this program, never an ePlace,
  NSP, or external GP artifact.
- Fixed macros remain at raw Bookshelf coordinates.

## Planned Pipeline

1. Load `output/adaptec1_papergrid_600/global.pl` as an explicit experimental
   smooth warm start.
2. Run exact HPWL with nearby exact-subgradient sampling, grouped HPWL bundle
   histories, and exact HPWL/overflow serious-null filtering.
3. Legalize with Greedy and Abacus, which assign cells to obstacle-free row
   segments.
4. Apply the existing legal discrete operators.
5. Run a fixed-topology x-only bundle.  Each trial is projected through the
   segment Abacus operator, snapped to sites, checked for full legality, and
   accepted only for strict exact-HPWL improvement.

## Evaluation

Primary metric: final legal exact HPWL on adaptec1.

Secondary metrics: selected pre-legal exact HPWL, overflow, accepted
pre-legal serious steps, accepted post-legal bundle steps, runtime, and
internal legality.

Matched references:

- Smooth warm start plus enhanced legalization: 74.548626M.
- Previous global bundle refinement plus enhanced legalization: 74.549788M.

The combined pipeline is positive only if it beats 74.548626M.  A lower GP
HPWL without a lower final legal HPWL is recorded as a negative result.
