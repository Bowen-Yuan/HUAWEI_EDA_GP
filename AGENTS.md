# Repository handoff rule

Before changing this repository, read every Markdown file in
`you should know about/`, starting with its `README.md`.

When a change affects architecture, modules, CLI/configuration, numerical
contracts, experiment retention/provenance, canonical inputs, important
results, known limitations, or Git workflow, update the corresponding files
in `you should know about/` and its `CHANGELOG.md` in the same commit.

Current source code and reproducible exact audits are the final authority.  If
the handoff documentation conflicts with code, verify the behavior and repair
the documentation rather than silently relying on stale text.
